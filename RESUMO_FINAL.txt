  🎯 OPÇÃO 1: INICIAR VIA NAVEGADOR (SEM SSH!)
═══════════════════════════════════════════════════════════════════

1. Faça upload do napoleon.zip para public_html
2. Descompacte o arquivo
3. Acesse: https://smartproeng.spweb.digital

   → O arquivo index.php vai tentar iniciar automaticamente!

OU acesse diretamente o painel de controle:

   👉 https://smartproeng.spweb.digital/start_server.php

   Este arquivo tem:
   ✓ Botão para iniciar servidor
   ✓ Status em tempo real
   ✓ Visualização de logs
   ✓ Instruções na tela


═══════════════════════════════════════════════════════════════════
  🖥️ OPÇÃO 2: TERMINAL DO CPANEL (SEM SSH EXTERNO!)
═══════════════════════════════════════════════════════════════════

1. Entre no cPanel
2. Procure "Terminal" (em Avançado)
3. Cole:

   cd ~/public_html/napoleon
   chmod +x start.sh
   ./start.sh

4. Pronto! ✅


═══════════════════════════════════════════════════════════════════
  ⚡ OPÇÃO 3: CRON JOB (INICIA AUTOMATICAMENTE SEMPRE!)
═══════════════════════════════════════════════════════════════════

1. No cPanel → Cron Jobs
2. Adicione:

   cd ~/public_html/napoleon && node dist/index.js > server.log 2>&1 &

3. Configure: @reboot
4. Salve ✅
